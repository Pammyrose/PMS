# 1. Introduction and User Roles

## 1.1 Purpose of the manual

This manual provides operating instructions for the DENR-CAR Performance Monitoring System (PMS). It explains how to access the application, monitor targets and accomplishments, maintain performance records, request corrections, generate reports, and carry out administrative tasks.

PMS centralizes physical and financial performance information by sector, program/activity/project (PAP), performance indicator, office, and reporting year. Access to records and actions depends on the signed-in user's role and assigned office.

## 1.2 User roles

| Role | Main responsibilities | Access limits |
| --- | --- | --- |
| Administrator | Manage accounts, PAPs and indicators; maintain performance records; import/export Excel; review locked-month requests; view history. | Administrative functions require an Administrator account. |
| Regional Office | Review consolidated performance, maintain authorized accomplishment records, review locked-month requests, export reports, and view history. | The interface may display the role as Region. User administration and PAP/import management belong to Administrator access. |
| PENRO | View authorized provincial performance, maintain assigned-office targets and accomplishments, track own correction requests, export reports, and view service-area history. | Cannot approve or decline correction requests. Data entry remains scoped to the assigned office. |
| CENRO / designated User | View assigned-office performance, enter accomplishments, request locked-month corrections, track decisions, and export reports. | Physical and financial targets are read-only. Cannot review requests or manage accounts. |

Provincial dashboard or export coverage does not grant permission to edit another office's records. If a required function is unavailable, ask the System Administrator to check your role and office assignment.

## 1.3 Before you begin

- Obtain your account and the approved PMS website address from the System Administrator.
- Use a computer with a web browser and a connection to the network where PMS is hosted.
- Have the office's verified targets, accomplishments, and supporting records available.
- For Excel tasks, use a spreadsheet application that can open .xlsx files and obtain the supported workbook format.
- Confirm the reporting year, sector, office, indicator, and unit of measurement before entering data.

# 2. Accessing the System

## 2.1 Logging in

1. Open your web browser and enter the approved PMS website address.
2. On the Login Page, enter your registered Email address.
3. Enter your Password.
4. Select the login button and wait for the Dashboard to load.
5. Check the name and role displayed in the top navigation bar. If the account or office is incorrect, contact the System Administrator before entering records.

Expected result: The system opens the dashboard appropriate to your account and displays the permitted navigation options.

[Screenshot 01: Login Page showing the email, password, and login controls.]

## 2.2 Navigation controls

The sidebar contains Dashboard, Sectors, Notifications, and other pages allowed for your role. Administrators can access Users & Roles. History is available to Administrator, Regional Office, and PENRO accounts. Use the menu button at the top to show or hide the sidebar when more table space is needed.

[Screenshot 02: Main interface showing the sidebar and signed-in role.]

## 2.3 Signing out

1. Save any pending work and check the save result.
2. Select Sign Out in the sidebar.
3. Confirm that the Login Page appears before leaving the computer.

## 2.4 Account or password assistance

If you forget your password or cannot sign in, contact the System Administrator. Account passwords can be changed through administrator user management. Do not include passwords in screenshots or support messages.

# 3. Using the Dashboard

## 3.1 Selecting the monitoring scope

1. Select Dashboard from the sidebar.
2. Choose an Office from the available options. All Offices is available only where your access permits it.
3. Select a Sector or All.
4. Choose the reporting Year.
5. Wait for the dashboard to refresh, then confirm the filters before interpreting the results.

Expected result: Dashboard summaries reflect the selected scope within your authorized access.

[Screenshot 03: Dashboard with Office, Sector, and Year filters.]

## 3.2 Reading performance information

Review Overall Performance, Financial Utilization, and the available PAP and indicator lists. Open the list controls where available to inspect the records included in the summary. Target Performance and Accomplishment Performance panels provide comparisons for the selected period and metric. Use the Physical or Financial selection and available period controls to examine the information needed.

Physical and financial comparisons represent different measures. Confirm the displayed metric and reporting period before comparing results or including them in a report.

The Monthly / Quarterly Delays Chart identifies delayed physical outputs for the displayed scope. Use it to locate areas that require follow-up, then check the corresponding sector records for details.

[Screenshot 04: Performance comparisons and delays chart with the selected metric and period visible.]

## 3.3 Checking an unexpected dashboard result

Verify the office, sector, year, and period first. Next, check whether the underlying records have been saved and whether a locked-month correction is still pending approval. A dashboard summary does not establish that every required office submission is complete.

# 4. Navigating Sector Performance Tables

## 4.1 Opening a sector

1. Expand Sectors in the sidebar.
2. Select GASS, STO, ENF, PA, ENGP, LANDS, SOILCON, NRA, PARIA, COBB, or Continuing Activities, as applicable.
3. Select the reporting Year on the sector page.
4. Use Search to locate a program, project, or activity and submit the search.
5. Locate the relevant performance indicator and office row.

Expected result: The table displays performance records available to your account for the selected sector and year.

[Screenshot 05: Sector page with the year, search field, PAP hierarchy, and office rows visible.]

## 4.2 Showing the columns you need

Open Columns and choose the available controls:

- Physical > Targets or Accomplishments to display physical data.
- Financial > Target or Accomplishment to display financial data.
- Show Months to expose monthly inputs when the relevant data columns are enabled.
- Summary to display the available performance summary columns.
- Pending to display pending-output information.
- Remarks to display explanatory notes.

Column visibility changes the presentation; it does not change your editing permissions. Some controls may be disabled until the relevant columns are shown. Use horizontal scrolling and the font-size controls where available to read wide tables.

[Screenshot 06: Columns menu with physical, financial, month, summary, pending, and remarks options.]

## 4.3 Understanding reporting periods

| Period | Months covered |
| --- | --- |
| Q1 | January to March |
| Q2 | April to June |
| Q3 | July to September |
| Q4 | October to December |
| Annual | The applicable full-year target or summary |
| To Date | The cumulative period represented by the displayed report |

Summary columns may include Annual, This Quarter, To Date, and accomplishment percentages. Read the table headings and period context. Aggregation can depend on the indicator type, so do not assume that every indicator is calculated by simply adding monthly values. Ask the responsible reporting personnel to clarify an indicator's required basis if needed.

# 5. Recording Physical and Financial Performance

## 5.1 Recording physical accomplishments

Available to: Authorized Administrator, Regional Office, PENRO, CENRO, and designated User accounts, within their permitted record scope.

1. Open the relevant sector and select the correct Year.
2. Locate the PAP, performance indicator, and office row.
3. Open Columns > Physical > Accomplishments and display monthly inputs using Show Months where needed.
4. Enter non-negative numeric values in editable month cells. Use the indicator's specified unit and verified office records.
5. Add Remarks where an explanation is needed and the field is available.
6. Select Save and wait for the result message.
7. For ordinary saved entries, reload or reopen the page and verify that the values were retained.

Expected result: Current and future accomplishment months save directly. Changes to locked months by PENRO, CENRO, or designated User accounts follow the request procedure in Section 6.

[Screenshot 07: Physical accomplishment entry with office, indicator, month values, and Save visible.]

## 5.2 Recording physical targets

Administrators and PENRO personnel can maintain physical targets through their permitted interfaces. CENRO and designated User accounts can view physical targets but cannot edit them.

1. Open the correct sector, Year, PAP, indicator, and office row.
2. Display Columns > Physical > Targets and the monthly inputs.
3. Enter the verified target values in editable cells.
4. Select Save, check the result, and verify the saved values.

If target cells are read-only, ask the responsible target-maintenance personnel to make the change.

## 5.3 Recording financial values

1. Open the relevant sector and Year.
2. Display Columns > Financial > Accomplishment or Target, according to the task and your permissions.
3. Display the month inputs where required and select the correct office row.
4. Enter non-negative numeric amounts using the unit or scale required by the table and approved source records.
5. Select Save and check the result message.
6. Verify the retained amounts before generating a report.

Financial targets are read-only for CENRO and designated User accounts. Their financial access is limited to accomplishments. Locked financial accomplishment months use the same correction-request process as physical accomplishments.

[Screenshot 08: Financial target/accomplishment columns with month inputs and office context.]

## 5.4 Checking a save

Read the displayed result carefully. A successful save and a request sent for approval have different outcomes. Pending corrections are not yet official accomplishment values. If validation fails, correct the fields identified by the message and save again. Do not leave the page or change the year while a save is in progress.

When a row includes both ordinary and locked-month changes, verify each value after saving. Do not assume that other values on a row with a queued correction have already been saved.

# 6. Correcting Locked Accomplishment Months

## 6.1 When months are locked

For PENRO, CENRO, and designated User accounts, months before the current month in the current year are locked. All months in an earlier reporting year are locked. Current and future months are not locked by this rule. The application uses Asia/Manila time to determine the current month.

Example: In October 2026, January to September 2026 are locked. October to December 2026 remain available for ordinary entry. All months of 2025 are locked.

Regional Office personnel and Administrators can directly maintain locked accomplishment records within their authorized access. PENRO personnel cannot approve or decline requests.

## 6.2 Sending a correction request

1. Open the appropriate sector and reporting Year.
2. Locate the office, indicator, and locked accomplishment month to be corrected.
3. Select or edit the locked input. Review the Edit Locked Accomplishment dialog when it appears.
4. Enter a clear reason explaining the correction and confirm the dialog.
5. Enter the corrected numeric value if the interface requires entry after confirmation.
6. Select Save to send the request.
7. Check that the system reports a locked-period change request sent for approval.
8. Open Notifications > Pending to confirm that the request appears.

Expected result: The request waits for Regional Office or Administrator review. The existing official value remains until approval.

Example reason: "Correcting the August accomplishment after verification against the signed office report; the previously entered value was 12 and the verified value is 15."

[Screenshot 09: Edit Locked Accomplishment dialog showing the reason field and confirmation control.]

# 7. Reviewing Requests and Notifications

## 7.1 Tracking your requests

Available to: PENRO, CENRO, and designated User accounts.

1. Select Notifications in the sidebar.
2. Choose Pending, Approved, or Declined.
3. Locate the request and check the sector, indicator, year, requested period, and values.
4. Review the decision and any reviewer notes.
5. For an approved request, reopen the sector table to verify the updated accomplishment. For a declined request, review the reason before preparing any revised request.

| Status | Meaning |
| --- | --- |
| Pending | The correction is awaiting review and has not yet replaced the official value. |
| Approved | The correction has been approved and applied to the accomplishment record. |
| Declined | The correction was not applied. Review the reason for decline. |

[Screenshot 10: Office-user Notifications page showing request status and decision details.]

## 7.2 Approving a correction

Available to: Administrator and Regional Office accounts.

1. Select Notifications and choose Pending.
2. Review the submitting user, office, sector, PAP, indicator, reporting year, changed months, requested values, and Reason for change.
3. Verify the correction against the office's supporting records and applicable reporting requirements.
4. Select Approve and confirm the prompt.
5. Check the success result and locate the request under Approved.

Expected result: The approved values are applied to the accomplishment record, and the requesting user can view the decision.

## 7.3 Declining a correction

1. Locate and review the pending request.
2. Select Decline to display the reason field.
3. Enter a clear Reason for declining.
4. Select Confirm decline.
5. Check the result and verify that the request appears under Declined.

Expected result: The proposed correction is not applied, and the requesting user can read the decision and reason.

[Screenshot 11: Reviewer Notifications page showing Approve, Decline, and the decline-reason field.]

# 8. Generating Excel Reports

Available to: Authorized accounts through their permitted office scope.

1. Open the relevant sector page.
2. Select the reporting Year.
3. Save ordinary edits and confirm any required correction approvals before generating the report.
4. Select Generate Excel.
5. Wait for the .xlsx download and open it in a spreadsheet application.
6. Check the sector, year, office coverage, indicators, physical and financial values, and reporting-period headings.
7. Save the file in the office's designated reporting location.

Expected result: The system downloads a workbook in the current WFP/performance-report layout using saved records. Unsaved inputs and unapproved corrections are not official exported accomplishments.

Regional Office and Administrator exports can cover regional records. PENRO exports cover the provincial office and its assigned CENROs. CENRO and designated User exports are restricted to their assigned office.

The current Generate Excel control passes the sector and year. Do not assume that every on-screen search, dashboard filter, or column-visibility selection will be reproduced in the workbook. Verify the downloaded file before submission.

[Screenshot 12: Generate Excel button and an opened workbook showing its sector, year, and report headings.]

# 9. Managing PAPs and Performance Indicators

Available to: Administrator accounts.

## 9.1 Adding a PAP and indicator

1. Open the relevant sector page and select the reporting Year.
2. Select Add PAP.
3. Enter or select the applicable hierarchy fields: Title, Program, Project, Activity, and any required sub-activity levels.
4. Follow the form guidance for levels that are not applicable.
5. Confirm the Year and enter the Performance Indicator.
6. Select Type of Indicator if applicable.
7. Select the responsible Office / Unit entries.
8. Select Save and check the result.
9. Search for the new record and verify its hierarchy, indicator, and office assignment.

Expected result: The new PAP/indicator record appears in the relevant sector and reporting year.

[Screenshot 13: Add PAP form showing hierarchy, indicator type, year, and Office / Unit selection.]

## 9.2 Updating a record

Use the available edit control for the PAP or indicator. Review the existing information, update the required fields, save, and verify the result. Changes to hierarchy or office assignments should be checked carefully because they affect which records users can locate and maintain.

## 9.3 Removing a record

Use Delete PAP or Delete row only after confirming the exact record and the office's authority to remove it. Review the confirmation dialog before proceeding. Deleting a PAP or row can remove related performance information; export or retain the required records before deletion according to office procedures. This manual does not assume an undo or restore function is available.

# 10. Importing Excel Data

Available to: Administrator accounts on supported sector pages.

## 10.1 Preparing a workbook

Obtain the approved or supported workbook layout from the responsible reporting personnel. Use .xlsx format. Preserve the worksheet structure, hierarchy, performance indicator names, office labels, and numeric columns required by the importer. Correct source-file errors before uploading.

The current upload validation allows files up to 50 MB; the hosting environment may impose a lower upload limit. A workbook exported by PMS is not automatically guaranteed to be a valid import template.

## 10.2 Previewing and importing

1. Open the sector page and select the intended reporting Year.
2. Verify the workbook and retain a copy of the current records where needed. Re-importing can reset or replace records for the selected sector, year, and data type.
3. Select Upload Excel and choose the .xlsx file.
4. Wait for Excel Import Preview to finish reading the file.
5. Review the detected record counts, PAP hierarchy, performance indicators, office assignments, and warnings.
6. If the preview is incorrect, select Cancel, correct the workbook, and upload it again.
7. When the preview is acceptable, select Import Excel.
8. Wait for the completion result, then check representative records and totals in the sector table.

Expected result: Supported workbook records are imported into the selected sector/year. Financial fields are included only where the workbook layout and importer support them.

[Screenshot 14: Excel Import Preview showing parsed rows, warnings, Cancel, and Import Excel.]

## 10.3 Import checks

Check office assignments, reporting year, hierarchy order, indicator text, period values, and any skipped records. Stop and consult the System Administrator or technical support if the preview associates values with the wrong offices or indicators. Do not confirm an import merely because the file can be opened.

# 11. Managing User Accounts

Available to: Administrator accounts through Users & Roles.

## 11.1 Creating an account

1. Select Users & Roles from the sidebar.
2. Select Create.
3. Enter Full Name and a unique Email Address.
4. Enter Password and Confirm Password. The password must contain at least eight characters, with uppercase and lowercase letters, a number, and a symbol.
5. Select the appropriate Role from the available options.
6. Select the assigned Office when required. PENRO accounts require a PENRO office; CENRO accounts require a CENRO office.
7. Submit the form using its save/create control.
8. Verify the new account's name, email, role, and office in the list.

Expected result: The account is created with the selected access and office assignment. Provide the account details to the intended user through the office's approved process.

[Screenshot 15: Users & Roles list and Create New User form, without a visible password.]

## 11.2 Updating an account or password

1. Locate the account and select the edit icon.
2. Update the name, email, role, or office as required.
3. Leave the password fields blank to retain the existing password. To change it, enter and confirm a new password that meets the requirements.
4. Save and verify the updated details.

## 11.3 Deleting an account

Locate the intended account, select the delete icon, and review the confirmation before proceeding. Confirm that removal is authorized and the account is no longer needed. The system prevents deletion of the account currently being used. Existing audit or submission records may display a deleted-user reference after removal.

# 12. Viewing Edit History

Available to: Administrator, Regional Office, and PENRO accounts. PENRO history is limited to users within the provincial service area.

1. Select History from the sidebar.
2. Apply the available filters for Module, User, Role, Edited Part, Action, and date range.
3. Apply the filters using the page's filter control.
4. Review the matching entries, including the responsible user, affected records, action, date, and available change details.
5. Use pagination to inspect additional entries.

Expected result: The page shows recorded changes that match the selected filters and your access scope.

History provides traceability for recorded changes. It does not itself reverse a change. If a value must be corrected, use the appropriate entry or correction-request workflow.

[Screenshot 16: History page showing filter controls and sample edit entries.]

# 13. Troubleshooting and User Support

## 13.1 Common issues

| Issue | What to check or do |
| --- | --- |
| Cannot sign in | Check the email and password. If the problem continues, ask the Administrator to verify the account or change the password. |
| Page will not open | Confirm the approved URL and connection to the hosting network. Record the displayed error and contact support. |
| Menu or action is missing | Confirm your role and office assignment. Some functions are available only to Administrators or Regional Office reviewers. |
| Target cells are read-only | CENRO and designated User accounts cannot edit targets. Contact the responsible target-maintenance personnel. |
| Office or indicator is missing | Check the sector, year, search, and office scope. Ask the Administrator to verify the indicator's office assignment. |
| Locked month asks for a reason | Enter a correction reason, confirm the dialog, save the request, and track it in Notifications. |
| Save is rejected | Read the validation message. Check numeric values, required reasons, reporting year, and office assignment. |
| Save result is unclear | Reopen the table and check the values and Pending requests before repeating the action. |
| Approved value is not visible | Check the same year, sector, office, indicator, and month, then refresh. If still incorrect, contact support with the request details. |
| Excel upload fails | Check .xlsx format, file size, supported worksheet layout, office names, and preview messages. Obtain the correct template if needed. |
| Import preview is incorrect | Cancel the import. Correct the workbook or ask technical support to check the mapping before proceeding. |
| Export contains unexpected records | Check the sector, year, saved data, and role-based office coverage. Screen searches and column visibility do not necessarily limit the export. |
| Session expired or page-expired message appears | Sign in again, reopen the task, and verify the saved records before re-entering anything. |
